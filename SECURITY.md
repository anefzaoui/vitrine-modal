# Security

Please report a security problem privately, through GitHub's
[private vulnerability reporting](https://github.com/anefzaoui/vitrine-modal/security/advisories/new)
(the **Security** tab, **Report a vulnerability**), not in a public issue. You'll get an answer
there; a fix is released before the details are made public.

Only the latest version is supported.
